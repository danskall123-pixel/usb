# Аниматор 2D

Самостоятельный браузерный редактор векторной 2D-анимации с костями, по принципам
**Moho / Anime Studio**. Не связан с остальными файлами репозитория: всё лежит в папке
`animator/`, работает офлайн, без сборки и без сторонних библиотек.

## Запуск

Нужен любой статический сервер (ES-модули не работают через `file://`):

```bash
cd animator
python3 -m http.server 8080
# открыть http://localhost:8080
```

При первом запуске открывается демо-проект — персонаж на костях машет рукой.
Проект автоматически сохраняется в браузере (IndexedDB); «Файл → Сохранить в файл»
выгружает его в `*.anim2d.json`. Файлы проекта, картинки и звук можно просто
перетащить в окно.

## Возможности

**Рисование (векторы как в Moho)** — точки с кривизной вместо ручек Безье: кривые гладкие
сами по себе, острота угла настраивается кривизной.
- Выделить точки (G, рамка/лассо), Трансформировать точки (T: перемещение, масштаб, поворот рамкой)
- Добавить точку (A: новые линии, продолжение, вставка в кривую, замыкание)
- Кривизна (C), Магнит (X), Толщина линии в точке (W), Разрезать контур (D)
- Кисть от руки (F) со сглаживанием, нажимом пера и сужением концов
- Фигуры (R): прямоугольник, овал, треугольник, многоугольник, звезда, стрелка, сердце, линия
- Выделить фигуру (Q, порядок фигур), Заливка/пипетка (P, Alt — взять стиль)

**Кости**
- Слой костей деформирует все вложенные слои: гибкая привязка по «силе» кости,
  жёсткая привязка точек (I) или целого слоя (L)
- Добавить (A), трансформировать (T), сменить родителя (P), сила кости (S)
- Управление костями (Z) с IK-цепочками, замком IK и ограничением углов;
  на кадре 0 — предпросмотр позы без порчи позы покоя

**Анимация**
- Кадр 0 — поза покоя; любые изменения на других кадрах автоматически становятся ключами
- Таймлайн: ключи слоёв, костей, точек, стиля и камеры; перетаскивание, копирование (Alt),
  выделение рамкой, копировать/вставить, 8 видов интерполяции
  (плавная, линейная, вход/выход, ускорение, замедление, ступенчатая, отскок, упругая)
- Режим кривых — графики значений с правкой ключей
- Луковая кожа, зацикливание, звук с волной на таймлайне и озвучкой при прокрутке
- Слой-переключатель (фазы рта и т. п.) с автоматическим липсинком по звуку

**Слои и эффекты** — векторные, группы (с маской), кости, переключатели, изображения, аудио;
непрозрачность, режимы наложения, размытие, тень; камера с панорамой, зумом и наклоном.

**Экспорт** — видео MP4/WebM (со звуком), анимированный GIF, PNG-последовательность в ZIP,
PNG и SVG текущего кадра.

## Горячие клавиши

`Пробел` — воспроизведение (удерживать и тянуть — двигать вид) · `←/→` — кадр ·
`Shift+←/→` — ключ · `Home` — кадр 0 · `K` — ключ слоя · `Ctrl+Z / Ctrl+Shift+Z` —
отмена/повтор · `Ctrl+C/V/X` · `Ctrl+D` — дублировать слой · `Delete` · `Ctrl+S / Ctrl+O` ·
`Ctrl+E` — экспорт · `Ctrl+0` — вписать · `F1` — справка. Клавиши инструментов работают
в любой раскладке; одна клавиша выбирает инструмент по типу слоя (как в Moho).

## Структура

```
animator/
├── index.html      # каркас интерфейса
├── editor.css      # тёмная тема
├── favicon.svg
└── js/
    ├── main.js      # запуск, меню, горячие клавиши, справка
    ├── app.js       # состояние и операции над документом
    ├── model.js     # слои, контуры, точки, кости
    ├── anim.js      # каналы, ключи, интерполяция
    ├── scene.js     # вычисление кадра: матрицы, скелет, деформация
    ├── render.js    # отрисовка (маски, наложение, эффекты)
    ├── viewport.js  # холст, оверлеи, навигация
    ├── tools.js     # инструменты
    ├── timeline.js  # таймлайн и режим кривых
    ├── panels.js    # инструменты, параметры, слои, свойства
    ├── io.js        # сохранение, импорт, экспорт
    ├── gif.js       # кодировщик GIF
    ├── playback.js  # воспроизведение со звуком
    ├── history.js   # отмена/повтор
    ├── ui.js, icons.js, util.js, demo.js
```

Для скриптов в консоли браузера доступен объект `window.anim2d`.
