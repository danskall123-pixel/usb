# Обои Студия (Wallpaper Studio)

Редактор обоев под Android / GrapheneOS: настраиваемые живые обои, статичные
обои из фото и живые обои из своего видео. Без Google-сервисов и без сети.

## Возможности
- **9 живых стилей** (свой `WallpaperService` + Canvas): Матрица, Звёзды (варп),
  Аврора, Неон-сетка, Снег, Созвездие, Плазма, Дождь, Светлячки.
- **Настройка «своих» живых обоев**: скорость, плотность, яркость, цвет и фон —
  с живым превью прямо в приложении. Кнопка **«Случайный стиль»**.
- **Фото на обои**: выбираешь картинку → ставится как статичные обои, с выбором
  экрана (главный / блокировки / оба).
- **Видео в живые обои**: выбираешь видео → зацикленное воспроизведение без звука
  как живые обои (`MediaPlayer`).
- Экономично: рисуем только когда обои видны, ниже частота кадров в
  энергосбережении; кадр собирается в offscreen-буфер → без мерцания.

## Сборка APK
Нужен Android SDK + JDK 17+ (проще всего — Android Studio: *Open* эту папку →
*Build → Build APK(s)*). Из консоли:
```bash
cd android-wallpaper-studio
# укажи SDK: переменная ANDROID_HOME или файл local.properties (sdk.dir=/путь/к/Android/Sdk)
./gradlew :app:assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

## Установка на GrapheneOS
1. Скинь `app-debug.apk` на телефон → открой → **Установить** (разреши установку
   из этого источника).
2. Открой приложение **Обои Студия**, настрой стиль и нажми **«Установить эти
   живые обои»** (или выбери фото/видео).
   Живые обои также доступны в **Настройки → Обои → Живые обои**.

## Структура
```
app/src/main/java/com/example/wallstudio/
  MainActivity.kt            — редактор (UI, превью, выбор фото/видео, установка)
  WallpaperRenderer.kt       — движок стилей (Матрица/Звёзды/Аврора)
  PreviewView.kt             — живое превью в приложении
  StudioWallpaperService.kt  — живые обои со стилем из настроек
  VideoWallpaperService.kt   — живые обои из видео
  Prefs.kt                   — сохранение настроек
```
Стили и параметры правятся в `WallpaperRenderer.kt`.
