# Cell Drift — клеточная стадия

Мобильная аркада про одноклеточный организм: ешь, расти, копи ДНК, перестраивай
своё тело в редакторе и не будь съеденным. Оригинальный проект, вдохновлённый
жанром «клеточной стадии».

**Главное правило проекта: ноль внешних ассетов.** В репозитории нет ни одного
`.png`, `.jpg`, `.svg`, `.mp3`, `.ttf`. Всё — организмы, фон, каустика, иконки
интерфейса, иконки PWA и звук — генерируется кодом во время выполнения.

## Запуск

Открыть `index.html` (лучше через любой статический сервер — ES-модули требуют
http). Сборка не нужна: чистый JavaScript, Canvas 2D, без npm и зависимостей.
Все пути относительные, проект рассчитан на подпапку GitHub Pages.

Цель — Safari на iPhone (iOS 16+), стабильные 60 FPS.

## Как это устроено

| Файл | Что делает |
|---|---|
| `src/main.js` | цикл с фиксированным шагом физики (60 Гц) и интерполяцией, состояния экранов, hit-stop, автоснижение качества |
| `src/spine.js` | позвоночник: цепочка сегментов, follow-the-leader с ограничением угла, распрямление, волна плавания, профиль толщины кривой |
| `src/render.js` | обводка тела catmull-rom → кривые Безье, объём градиентами, эффекты |
| `src/parts.js` | каталог частей и их процедурная отрисовка (рты, глаза, жгутики, плавники, шипы, броня, яд, электро) |
| `src/noise.js` | своя реализация value- и simplex-шума, fbm, ridged, curl |
| `src/background.js` | параллакс, бесшовный тайл каустики, лучи, планктон, пузыри, течения |
| `src/particles.js` | пул частиц на структуре массивов |
| `src/creature.js` | ИИ: блуждание, преследование, бегство, boids |
| `src/editor.js` | редактор организма: части, форма тела, статы, превью |
| `src/audio.js` | синтез звука Web Audio API |
| `src/icons.js` | генерация иконок PWA на canvas → data-URL → Blob-манифест |
| `src/save.js` | localStorage, валидация повреждённых данных |

## Управление

- Организм плывёт к точке касания, скорость зависит от расстояния пальца.
- Второй палец — ускорение (тратит выносливость).
- В настройках есть виртуальный джойстик.
- Атака — автоматически при контакте ртом; спецорган — кнопка справа.

## Технические решения, о которых стоит знать

- **Размытие фона в редакторе** — не `filter: blur` (дорогой на iOS), а
  даунскейл кадра в 8 раз и обратный апскейл со сглаживанием.
- **Каустика** — тайл периодического шума считается один раз при запуске;
  движение даёт сдвиг двух копий, глубину — маска в половинном разрешении.
- **Иконки PWA** — рисуются на canvas, `manifest.json` пересобирается в памяти
  и подключается через Blob-URL (в самом файле иконок нет).
- **Производительность** — пулы без аллокаций в кадре, culling по камере,
  `devicePixelRatio` ограничен двойкой, автоснижение частиц и качества фона
  при падении FPS ниже 50 и восстановление, когда запас вернулся.
